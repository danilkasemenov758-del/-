# Точка праздника — Telegram Mini App prototype

Статический прототип мини-приложения. Сейчас работает без сборки и без сервера: откройте `index.html` в браузере.

## Что уже есть

- Проверка доступа и экран "Доступ не найден".
- Главный экран актера.
- Список заказов.
- Карточка заказа.
- Реквизит и фильтры.
- Комплект реквизита с действием "Взять комплект".
- Программы и карточка программы.
- "Сохранено" для офлайн-доступа.
- Профиль.
- Локальная очередь действий в `localStorage`.
- Подключены SVG-ассеты из Figma: логотип, персонажи и карточки разделов.
