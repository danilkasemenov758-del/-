# Запуск в Telegram

Telegram Mini App не открывается у сотрудников из `file://`. Нужен публичный HTTPS-адрес приложения.

## 1. Создать бота

1. Откройте Telegram.
2. Найдите `@BotFather`.
3. Отправьте `/newbot`.
4. Укажите название, например `Точка праздника`.
5. Укажите username бота, например `tochka_prazdnika_bot`.
6. BotFather выдаст токен. Его нельзя публиковать в коде фронтенда.

## 2. Разместить Mini App

Для первой проверки можно использовать любой HTTPS-хостинг:

- Vercel
- Netlify
- GitHub Pages
- свой сервер с HTTPS

Загрузить нужно содержимое этой папки:

- `index.html`
- `styles.css`
- `app.js`
- `assets/`

После публикации получится URL вида:

`https://your-domain.example/`

## 3. Подключить кнопку Mini App

В BotFather:

1. `/mybots`
2. выбрать бота
3. `Bot Settings`
4. `Menu Button`
5. `Configure menu button`
6. указать текст кнопки, например `Открыть приложение`
7. указать HTTPS-URL Mini App

## 4. Что подключить после проверки UI

- серверную проверку Telegram `initData`;
- базу сотрудников и ролей;
- синхронизацию действий: принятие заказа, реквизит, комплекты;
- Google Таблицу как отчет;
- хранение музыки и сценариев.

Сейчас прототип использует локальные мок-данные и `localStorage`, поэтому он подходит для проверки интерфейса и сценариев, но еще не для реальной команды.
